# Демо CRM для автосервиса

Интерактивная демо-версия CRM: запись по постам, заказ-наряды, клиенты и автомобили, склад, прайс, отчёты и зарплата мастеров.

**Открыть:** https://ivanalekseevich683-a11y.github.io/crm-demo/

Работает в браузере на компьютере и на телефоне, устанавливать ничего не нужно.

## Как пользоваться

- Демо открывается сразу под администратором. Данные вымышленные, можно смело всё пробовать.
- Всё, что вы добавите, сохраняется только в вашем браузере. Кнопка «Сбросить демо-данные» вверху вернёт исходный вид.
- Если выйти из программы, можно войти заново:
  - `admin` / `admin123` — администратор, видит всё;
  - `master` / `master123` — сотрудник, не видит выручку, отчёты и настройки.

## Как открыть на телефоне как приложение

- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» или «Установить приложение».

На главном экране появится значок CRM. Демо будет открываться без адресной строки браузера, как обычное приложение.
